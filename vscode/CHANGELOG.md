# Changelog

## 0.1.0

First release.

- Live 3D preview of `.arch3d` and Mermaid `architecture-beta` (`.mmd`) files, beside the editor.
- Click a block to jump to its definition; double-click to fly in.
- Errors and warnings in the editor and the Problems panel.
- Save the preview as PNG; export a single offline HTML file.
- Syntax colouring for `.arch3d`.
